# 実際に確認した範囲

[原本の版・コミット・配布物ハッシュ](reference-build.json)。元の調査は macOS 26.2 arm64 で行った。会話は通常利用データと分けた Dev 用プロファイルで、配布版の実行ファイル・サーバー・レンダラーを使用した。アップデート機能などに通常起動との違いがある。ネイティブメニューは通常の Beta の公開メニュー項目34件を別に確認した。

- 原本の [確認した遷移](transitions.tsv) は機能 ID、観測結果、残る条件、あれば対応する矩形採取 ID を持つ。フォルダー追加、下書き、逐次表示、承認・拒否、停止、エラー、再起動、検索・整理・キュー、Git の動作を含む。コーディングエージェントの会話は実際のアダプターと決定的なテスト応答を組み合わせた。
- worktree は選択だけでは増えず、初回送信後に作業先が1から2へ増加した。保存先の準備障害では失敗カードと Retry が現れた。選択コミットでは対象のファイルだけが記録され、選外の編集は残ったが、既にステージ済みだった部分は未ステージに戻った。
- Swift 配布版13状態を Accessibility で操作した。テスト用モデルの HTTP 応答は初回200、再起動後200、故意の失敗401。2通目に以前の user / assistant 履歴が含まれた。終了時に一時 Keychain 項目を削除し、実行領域を検査した。先行試作ではローカルモデルの実推論も1回通した。[先行試作と再現方法](../../pi-keychain-probe/README.md)
- 端末の追試では SwiftTerm に `pwd -P` を実入力し、Return 前のエコーと実行後に表示された作業先を照合した。フォルダー選択は直接入力経路で登録を確認。OS パネル経由は表示までで、確定・登録は未検証。
- Swift の補助プロセスが指定するテレメトリ設定を同梱 SDK 1.6.1 の判定関数に渡し、既定値と有効にした対照条件を比較した。[結果](pi-telemetry.json) · [再実行用コード](../methods/check-pi-telemetry.mjs)

外部アカウント・他端末が必要な操作には未検証の行がある。公開版に含めたのは結果の記述と構造化した数値。生の HTTP ヘッダー、鍵、会話データベース、スクリーンショット、録画、ログ、個人の設定値は公開していない。
